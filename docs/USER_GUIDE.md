# 班主任 AI 工作台 · 使用文档

> 面向使用者（班主任 / 辅导员）的日常操作手册。
> 开发与协作规范见 `AGENTS.md`、`PRD.md`，开发进度见 `docs/PROGRESS.md`。

---

## 1. 这是什么

**班里大小事，一个工作台。**

一个装在自己电脑上、数据不出本机的班主任个人工作台。分工很清楚：

- **学校学工系统**：正式审批、上报、统一留痕（官方的账本）
- **本工作台**：日常发现、过程跟进、本地归档、材料整理（你自己的账本）

它是 Local First 应用：不需要注册登录、没有后端服务器、不联网也能用绝大多数功能。学生数据全部保存在你自己电脑的浏览器数据库（IndexedDB）里。

## 2. 安装与启动

### 方式 A：安装桌面版（推荐）

| 平台 | 安装包 | 说明 |
|---|---|---|
| macOS（Intel / Apple Silicon） | `班主任AI工作台_0.1.0_universal.dmg` | 打开后把 App 拖进「应用程序」 |
| Windows（有网） | `班主任AI工作台_0.1.0_x64-setup-online.exe` | 安装时若缺 WebView2 会自动下载 |
| Windows（无网/机房） | `班主任AI工作台_0.1.0_x64-setup-offline.exe` | 内置运行时，全程无需联网 |

首次打开若系统提示「无法验证开发者」：

- **macOS**：右键 App → 「打开」，或到 系统设置 → 隐私与安全性 → 点击「仍要打开」
- **Windows**：点击「更多信息」→「仍要运行」

（因为安装包尚未购买代码签名证书，属于正常提示，本应用不含网络上传行为。）

### 方式 B：浏览器本地运行（开发者 / 试用）

需要 Node.js 22.13+：

```sh
npm install
npm run dev        # 打开 http://127.0.0.1:5173/workbench
```

### 演示模式

不想导入真实学生、想先看看功能？访问：

```
/workbench?mode=demo
```

会加载 100 名虚构学生的完整演示数据。**演示模式禁止导入真实花名册**，刷新即重置，可放心把玩。

## 3. 第一次使用：三步配置

1. **导入花名册**：「我的班级」→ 下载模板（CSV / XLSX）→ 按模板填好 → 导入。
   模板里「字段说明」工作表写清了每个字段的必填与写法，照着填可避免字段统计错位。
   导入后立即形成班级看板与学生档案；**以学号建立稳定身份**，后续所有记录都挂在学生身上。
2. **配置学工系统链接**（可选）：左侧栏「学工系统」入口 → 粘贴你们学校的学工系统网址（http/https）。
   配好后，待办、谈话卡上的「去学工系统回填 / 粘贴」按钮会直接跳转系统默认浏览器。
   *开源版本不预设任何学校地址，每位老师各自配置。*
3. **配置 AI Key**（可选）：「AI 设置」→ 选供应商 → 填 Key。
   预置了 DeepSeek、Kimi、智谱 GLM、通义千问等常见供应商，支持联网测试连通性。
   **Key 只保存在本机**，永不出现在调试信息里；不配置 AI 也完全不影响其他功能。

## 4. 功能页导览

| 页面 | 干什么用 |
|---|---|
| **首页** | 今日工作台：今日待办、今日需谈话学生、关键指标一眼可见 |
| **我的班级** | 班级看板与学生档案：成绩、挂科、出勤等导入数据的长期趋势 |
| **特殊关爱** | 关爱学生的跟进记录与关注点。*只记录事实、整理输入、形成跟进，不做任何诊断或风险预测* |
| **事务** | 班级事件登记与流转（如冲突、请假、宿舍问题） |
| **待办** | 日常与事件衍生的待办事项，支持设置复查日期 |
| **谈心谈话** | 谈话记录台账、谈话模板库；支持从事件/待办一键发起谈话，谈话完成后可自动生成复查待办 |
| **评奖评优** | 奖助 candidates 管理，AI 辅助推荐（经隐私网关） |
| **升学就业** | 毕业班去向跟进 |
| **材料输出** | 评语、事迹材料、情况说明等常用文书生成，支持导出 TXT、复制、AI 润色 |
| **AI 设置** | 供应商 / 模型 / Key 管理、联网测试、调试面板 |

### 三个使用习惯建议

- **谈话记录两条路径**：从某条事件/待办点「发起谈话」，记录会与事件关联并自动生成复查待办；直接在「谈心谈话」页新建则是独立记录，不产生待办。
- **模板库**：常用的谈话开场、追问思路可以存成模板，台账在模板库之前，日常从台账进。
- **导出**：所有导出（备份、谈话记录 Markdown、材料 TXT、模板包 JSON、花名册模板）桌面版统一保存到系统「下载」目录，重名自动加序号，界面会提示落盘路径。

## 5. AI 功能与隐私

工作台的 AI 设计原则是**最小必要 + 人工把关**，不是把学生信息直接扔给大模型：

1. **隐私网关（Privacy Gateway）**：任何涉及学生的 AI 操作，先在本地判定任务必要性 → 最小化 → 去标识化（学生被替换为稳定代号）→ 你逐条确认 Prompt → 才复制/发送给 AI。
2. **返回同样本地处理**：AI 返回内容粘贴回工作台后，本机自动恢复真实身份 → 你人工审核 → 确认后才写入记录。
3. **直连模式**（可选）：配置 Key 后可一键直调，跳过手工复制粘贴，但同样走本机去标识化；润色统一只有一个入口（AI 润色对话框）。
4. **永不进入 AI 的内容**：身份证号、手机号、住址、宿舍号、宗教、性取向默认被硬性拦截；家庭与心理信息只在与任务确有关联时泛化使用。
5. 工作台**不会自动调用**第三方 AI，也不会通过 URL 携带学生材料。

## 6. 数据安全与备份

- 数据存在**当前浏览器 / 当前电脑**的 IndexedDB 里。换电脑、换浏览器、清除浏览器数据 = 数据消失，请定期备份。
- **导出完整本地备份**：左下角 → 导出完整本地备份 → 得到一个 JSON 文件（含全部学生资料，妥善保管）。
- 备份文件含真实姓名等敏感信息，不要发群、不要上传网盘公共目录。
- 系统不设密码。台式机在办公室请配合系统锁屏使用；有更高要求时可把工作台装在个人电脑而非公用机。

### 清除全部数据（危险区）

左下角「清除全部数据…」用于恢复出厂（例如误导入了整份花名册、想换一届学生从头开始）。流程设计以**不丢数据**为第一优先级：

1. **强制备份**：点击后第一步就是导出完整备份文件，**备份成功之前「永久清除」按钮始终不可用**；
2. 备份完成后，第二步才能点「永久清除全部数据」；
3. 如果确实不需要备份文件，走逃生口「无需备份，直接清除」——**必须连点 3 次**确认；
4. 即便如此，清除时应用仍会在本机数据库里自动留一份「清除前快照」作为最后防线；
5. 清除后恢复为默认状态（保留内置谈话模板），可重新导入花名册。

### 演示数据会不会残留？

不会。演示模式（100 人虚构数据）和「仅本次会话」模式的数据**只存在内存里**，刷新或关闭页面即全部消失，不写入本机数据库，因此也不需要清理入口。侧栏左下角会标明当前所处的是哪种数据空间。

## 7. 常见问题

**Q：某个按钮点了没反应？**
先用最新安装包。0.1.0 早期包在桌面端存在外链不跳转、下载/复制失效的问题（已修复）。浏览器版均正常。

**Q：换了个浏览器打开，数据不见了？**
数据按浏览器隔离。同一台电脑请固定用同一个浏览器（或改用桌面版，数据独立保存）。

**Q：日期好像差了一天？**
已知口径问题：系统以 UTC 日期为「今天」，北京时间 0–8 点期间会比实际早一天。新增数据建议避开该时段，或以次日视角复核。此问题在修复计划中。

**Q：AI 请求报错 / 空回复？**
「AI 设置」的调试面板会保留原始返回证据（状态码、usage、finish_reason）。多数情况是 Key 错误、额度用尽或网络问题；空正文会被自动分类并给出建议动作。

**Q：怎么更新到新版本？**
重新下载安装包覆盖安装即可；本地数据在系统用户目录，不受覆盖影响。稳妥起见，升级前先导出一次完整备份。

## 8. 给协作者与 AI 智能体

如果你要在此基础上继续开发（自己动手或交给 AI 编程助手）：

1. **先读三份文件**：`AGENTS.md`（不可违背的红线：Local First、隐私流程、禁止大重构）、`PRD.md`（产品需求）、`docs/PROGRESS.md`（已做了什么、为什么这么做）。
2. **环境**：Node.js 22.13+；`npm install && npm run dev`。
3. **测试**：`npm test`（单元）与 `npm run test:browser`（Playwright 回归）——UI 选择器被测试锁定，改样式前先看测试。
4. **打包**：`npm run desktop:dmg` / `desktop:dmg:univ` / `desktop:win`，产物在 `dist-desktop/`，细节见 README「桌面端打包」。
5. **入口约定**：正式入口 `/workbench`（根路径 `/` 等效），演示入口 `/workbench?mode=demo`，勿改动。
