# PRD｜班主任 AI 工作台

## 1. 产品定位

### 一句话
一个面向高职班主任的「本地优先、先脱敏后 AI」工作流工具。

### 核心价值
不是让班主任“更会写 Prompt”，而是：
- 用说话代替打字；
- 用固定流程代替反复整理；
- 用本地处理降低敏感信息外泄风险；
- 把成熟班主任经验固化为可复用工作流；
- 把事务性时间还给学生。

## 2. 两个交付物

### A. AI 班主任工作台
本地优先 Web App / PWA。

### B. HTML 汇报
16:9 HTML 演示页，用于 20–30 分钟优秀班主任经验分享。
要求：
- 键盘左右键翻页；
- 全屏；
- 页码/进度；
- 演讲者备注可选；
- 所有资源本地；
- 不依赖远程 CDN；
- 可从汇报页无缝跳转工作台 Demo，再返回原页；
- 后续内容可独立迭代。

# 3. 功能架构

## M0｜首页：今天我要做什么
不要聊天框。

首页只保留 6 个一级入口，降低首次使用复杂度：

1. 隐私脱敏
2. 谈心谈话
3. 班级分析
4. 学业 / 考勤
5. 就业 / 升学
6. 班主任事务

二级入口放在右上角或设置区：
- Prompt / 工作流模板库
- 本地安全中心
- AI 设置
- 演示模式

主题班会并入“班主任事务”。

首页顶部固定显示：
> 本地优先：原始数据默认不上传。需要使用外部 AI 时，请先完成脱敏与人工确认。

## M1｜隐私脱敏中心【最高优先级】

### 目标
老师上传一个学生相关文档，系统在本机完成识别、替换、泛化、复核，并输出脱敏版本。

### 输入方式
- 直接粘贴文本
- 上传 DOCX
- 上传 XLSX/CSV
- 上传 TXT
- 上传可解析 PDF

### 花名册
允许老师导入本地班级花名册：
- 姓名
- 学号
- 班级
- 手机号（可选）
- 宿舍（可选）

仅用于本地精确识别。
支持多个班级。
花名册原始内容不上传。

### 自动识别
至少识别：
- 姓名
- 学号
- 手机号
- 身份证号
- 邮箱
- 班级信息
- 地址/宿舍（规则识别 + 人工复核）

### 稳定映射
例：
张三 → S007
李四 → S012

同一学生跨多个文档仍保持一致代号，直到用户清除映射。

### 泛化
允许用户选择：
- 保留原信息
- 模糊化
- 删除

例：
“浙江省绍兴市越城区……” → “浙江省某市”
“2026年3月15日” → “2026年3月”
“确诊为××” → “存在心理健康/医疗相关情况”

### 最小必要模式
用户先选择任务：
- 谈心谈话
- 学业分析
- 就业指导
- 班级统计
- 其他

系统根据任务提示：
> 以下字段可能不是完成当前任务所必需，建议删除。

V1 可以规则实现，不要求大模型判断。

### 对照复核
三栏或左右对照：
- 原始内容
- 脱敏后内容
- 风险/替换清单

高亮每一处变更。
允许点击恢复、手工标记、手工替换。

### 风险提示
状态：
- 高风险：仍检测到明确身份证/手机号等
- 中风险：包含较多组合识别信息
- 已复核：用户确认

“低风险”不得等价表达为“绝对安全”。

### 输出
- 复制脱敏文本
- 下载脱敏 TXT
- 对 DOCX/XLSX 尽可能导出结构化脱敏副本
- 生成“用于 AI 的脱敏摘要”
- 进入后续工作流

### 本地数据
- IndexedDB
- 可选“仅本次会话，不保存”
- 一键清空：
  - 花名册
  - 映射
  - 历史
- 可选本地加密保险箱（V1.1）

## M2｜谈心谈话助手

### 场景 A：谈话前
老师输入/粘贴学生近期情况（必须先过脱敏层）。

输出标准 Prompt，要求 AI：
- 只根据已知事实；
- 不做心理诊断；
- 不贴标签；
- 生成 5–8 个开放式问题；
- 区分“需要了解”“需要确认”“后续跟进”。

### 场景 B：谈话后
老师可直接使用语音输入法口述谈话经过。

系统本地先脱敏，再生成：
- 谈话基本情况
- 学生主要表达
- 客观事实
- 班主任已采取措施
- 待跟进事项
- 下次跟进时间建议

### 口述辅助
提供一个小卡片：
> 建议直接使用 Typeless / 豆包语音输入法 / 微信输入法说话输入，不需要重新整理语言。

并提供 30 秒口述模板。

## M3｜班级情况分析

### 输入
导入脱敏后的：
- 成绩表
- 考勤表
- 活动参与
- 竞赛/获奖
- 请假统计

### 本地分析优先
不用 AI 即可完成：
- 缺勤次数排行
- 连续变化
- 成绩变化
- 多指标交叉筛选
- 班级基础统计

### 输出
- 班级概览
- 值得班主任关注的“变化”
- 每一条提示都必须显示依据
- 不使用“危险学生”“问题学生”等标签

### AI
仅在用户点击后，基于脱敏统计摘要生成“班主任下一步工作建议”。

---

## M4｜学业 / 考勤关注助手

面向高职常见场景：
- 多次迟到
- 旷课
- 挂科风险
- 成绩连续下降
- 实训/实习异常

输出：
- 事实摘要
- 建议核实的问题
- 第一次沟通提纲
- 后续追踪清单

AI 不能自动给学生下风险结论。

---

## M5｜就业与专升本助手

### 就业
- 招聘 JD 提取岗位要求
- 学生简历优化
- 简历与岗位匹配
- 模拟面试题
- 求职计划拆解
- 实习复盘

### 专升本
- 目标拆解
- 阶段复习计划
- 周计划
- 学习复盘
- 备考谈话提纲

个人材料必须经过脱敏后再进入 AI。

## M6｜主题班会助手

输入：
- 年级
- 专业
- 主题
- 班会时长
- 希望的互动程度

输出：
- 班会目标
- 20/30/45 分钟流程
- 互动活动
- 讨论问题
- 案例
- 主持提示
- 班会后任务

模板主题：

- 学风建设
- 职业规划
- 实习安全
- 网络安全
- 诚信考试
- 就业
- 专升本
- 心理健康（必须附“非诊疗工具”提醒）

## M7｜班主任事务助手

固定任务，不让老师从空白 Prompt 开始：
- 通知润色
- 活动方案
- 班级总结
- 工作总结
- 会议纪要整理
- 新闻稿
- 学生评语
- 家校/家长沟通（适用场景下）
- 奖助材料文字整理
- 评优材料
- 班干部会议议程

每个任务采用结构化表单 + 可编辑模板。

## M8｜Prompt / 工作流模板库

目标：把优秀班主任经验沉淀为模板。

每个模板包含：
- 使用场景
- 输入字段
- 隐私等级
- 是否必须先脱敏
- Prompt 模板
- 输出格式
- 禁止项

支持：
- 收藏
- 复制
- 修改
- 自建模板
- 本地导入/导出 JSON 模板包

以后可以由学校统一发“工作流模板包”，但不传学生数据。

---

## M9｜AI 出口

V1：
- 显示最终 Prompt
- 复制
- 选择常用 AI 链接
- 点击后打开新标签页
- 不自动传内容

V2：
- 自定义 OpenAI-compatible API
- 自带 Key
- 自定义 Base URL
- Ollama / 本地模型
- 单独开关，默认关闭

必须明确：
> API 模式可能把当前脱敏内容发送给用户配置的第三方服务，请确认后继续。

---

## M10｜本地安全中心

显示：
- 当前是否离线
- 本地保存的数据类型
- 花名册数量
- 映射数量
- 历史任务数量
- 清除按钮
- 会话模式
- 本地加密状态

提供“演示模式”：
- 自动加载虚构数据
- 禁止读取真实花名册
- 汇报现场一键使用

# 4. 关键产品流程

## 流程 1：文档脱敏
上传文档
→ 本地解析
→ 花名册匹配
→ 规则识别
→ 稳定映射
→ 泛化建议
→ 最小必要提示
→ 人工复核
→ 导出 / 进入 AI 工作流

## 流程 2：谈话后整理
语音输入法口述
→ 粘贴文本
→ 本地脱敏
→ 人工确认
→ 生成标准 Prompt
→ 复制到教师自己的 AI
→ 粘贴 AI 输出回来（可选）
→ 本地形成谈话记录

## 流程 3：班级分析
导入成绩/考勤
→ 本地统计
→ 发现变化
→ 人工选择需要关注的对象
→ 自动生成脱敏摘要
→ 再交给 AI 形成沟通建议

# 5. 隐私分级建议

### L0：公开/通用
班会主题、公开政策、通用文案
→ 可直接使用 AI

### L1：一般个人信息
已去标识化的学业、考勤等
→ 脱敏后再用

### L2：敏感个人信息
心理、医疗、家庭经济困难、身份证等
→ 默认本地保存；只有任务确有必要时形成最小化摘要

### L3：高风险原始材料
心理咨询原始记录、完整困难认定材料、身份证件扫描件等
→ 工作台只做本地整理/脱敏；默认禁止直接进入外部 AI

# 6. V1 明确不做

- 不做账号登录
- 不做云数据库
- 不做班级数据云同步
- 不做自研语音转文字
- 不做心理诊断
- 不做自动“重点学生”定性
- 不做扫描件 OCR
- 不做直接发送微信/短信
- 不做统一托管所有老师 API Key
- 不做学校级管理后台

# 7. HTML 汇报框架（正式版）

目标时长：20–30 分钟。
建议主讲约 25 分钟，预留机动时间。
整体叙事不是“介绍 AI 软件”，而是：
**效率 → 方法 → 安全 → 工具化 → 回到育人。**

## 15 页结构

### 1｜封面
《从“会用 AI”到“人人可用”——AI 赋能高职班主任工作的实践与探索》

副标题可选：
“一个本地优先的班主任 AI 工作台实践”

### 2｜班主任真正缺的是什么？
核心大字：
**时间**

辅助信息：
谈心、考勤、材料、班会、就业、数据、总结……

### 3｜我的核心判断
> AI 不应该替代育人，
> 应该替代大量机械的信息加工。

### 4｜第一步甚至不是学 Prompt
核心：
**先用说话代替打字。**

推荐展示：
- Typeless
- 豆包语音输入法
- 微信输入法

强调：
工作台不自研语音识别，只承接“说话→文字”后的内容。

### 5｜我的班主任 AI 工作流
展示 6 个一级入口：
- 隐私脱敏
- 谈心谈话
- 班级分析
- 学业 / 考勤
- 就业 / 升学
- 班主任事务

### 6｜案例：一次谈心谈话
传统：
谈完 → 回忆 → 打字 → 整理 → 写记录

新方式：
谈完 → 口述 → 脱敏 → AI 整理 → 人工确认

### 7｜真正的问题来了
标题：
**学生信息能不能直接交给 AI？**

核心句：
> 能做，不等于应该直接做。

### 8｜法律和政策边界
展示：
- 《个人信息保护法》
- 敏感个人信息
- 医疗健康信息
- 教育部门关于学生心理健康数据安全的相关要求

页面右下角必须有正式来源区域。
后续由内容阶段补充最终准确引用。

### 9｜为什么尤其要重视心理健康信息
展示权威研究或官方数据。
必须明确：
> 抑郁症状检出率 ≠ 临床诊断率

目的：
说明数据重要性与敏感性并存。

### 10｜不是所有 AI 都应该先联网
核心观点：

> 很多人做 AI 产品时，第一反应是联网。
> 但班主任学生信息管理，恰恰更需要本地优先。

视觉主句：
**Local First · AI Second**

### 11｜我的三步脱敏法
核心：
**映射 + 泛化 + 最小必要**

必须配虚构案例前后对照。

### 12｜现场 Demo：自动脱敏中心
从 HTML 汇报直接进入工作台演示模式。

演示流程：
虚构 Word / 文本
→ 自动识别
→ 稳定映射
→ 泛化
→ 人工复核
→ 生成脱敏版本
→ 生成 AI Prompt

Demo 完成后可一键返回第 12 页。

### 13｜从 Prompt 到工作流
核心观点：

> 如果今天只给大家 10 个 Prompt，
> 回去以后很可能就躺在收藏夹里。

因此把经验固化成工作流。

### 14｜开箱即用
展示工作台 6 个入口。

强调：
- 不绑定某一个模型
- 不统一收集学生数据
- 不要求复杂 Prompt
- 不要求老师配置开发环境
- V1 不强制 API

### 15｜把时间还给学生
核心结束语：

> AI 可以帮我整理信息，
> 但真正需要班主任亲自完成的，
> 始终是理解学生、陪伴学生、影响学生。

最后一句：
> 我希望 AI 做的事情越来越多，
> 而我和学生面对面的时间，也越来越多。

## HTML 演示交互要求

- 16:9
- 键盘左右键翻页
- 全屏
- 页码 / 进度
- 支持讲者备注
- 所有资源本地
- 不依赖远程 CDN
- 支持从第 12 页进入工作台演示模式
- 支持从工作台返回原演示页
- Demo 数据必须为虚构数据
- 断网情况下仍能完成汇报和本地 Demo

# 8. 成功标准

一个没有 AI 技术背景的班主任第一次打开后，应能在 3 分钟内完成：

1. 选择“谈心谈话助手”；
2. 粘贴一段口述文字；
3. 看懂脱敏结果；
4. 人工确认；
5. 获得可直接复制的 Prompt；
6. 粘贴到自己常用 AI 中使用。

如果这件事做不到，说明产品仍然太复杂。
