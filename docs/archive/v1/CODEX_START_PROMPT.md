## 最重要的产品变化

V1 更像“脱敏工具 + AI 功能入口”。

V2 改为真正的班主任本地工作系统：

**班级 → 学生 → 事件 → 待办 → 谈话/处理 → 跟进 → 材料输出**

产品口号：

**班里大小事，一个工作台。**

学校正式学工系统负责上报和正式留痕；
本工作台负责班主任日常过程管理和个人本地归档。

## 重要架构变化

教师在本地可以查看完整学生信息。

不要再要求老师为了查看学生资料先脱敏。

脱敏能力应重构为底层的 AI Privacy Gateway：

只有在用户点击“AI 帮我……”时才：
最小必要 → 去标识化 → 人工确认 → AI → 本地恢复身份 → 人工审核。

## 底层能力必须复用

现有项目如果已经稳定实现：
- 本地文件解析
- 花名册
- IndexedDB
- 稳定映射
- 脱敏引擎
- 人工复核
- PWA
- 网络隔离
- 自动测试

则禁止无理由推倒重写。

本次主要重构：
- 信息架构
- 首页
- 学生库
- 学生详情
- 事件
- 待办
- 谈心谈话
- 评奖评优
- 升学就业
- 材料输出
- AI 调用边界
