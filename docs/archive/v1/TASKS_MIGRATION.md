# 最重要的验收场景

## 场景 A：缺勤
班委反馈学生缺勤
→ 30秒内登记
→ 生成待谈话
→ 谈后成文
→ 设置复查
→ 复制学工系统
→ 本地留痕

## 场景 B：挂科
成绩导入
→ 找到挂科学生
→ 点学生
→ 发起学业谈话
→ 形成行动计划
→ 建跟进任务

## 场景 C：情感谈话
粗略口述
→ 一键标准成文
→ AI 模式下姓名不离开本地
→ 返回后恢复姓名
→ 人工审核

## 场景 D：评奖评优
筛选候选
→ 看材料状态
→ 补材料
→ 形成推荐意见

## 场景 E：专升本/就业
一眼找到：
- 未明确方向
- 无简历
- 无行动计划
并能直接转谈话/待办。
