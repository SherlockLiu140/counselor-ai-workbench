## 已知问题和技术债

1. DOCX/XLSX 暂不生成结构化副本；TXT 导出减少隐藏图片、批注、附件和元数据绕过脱敏的机会。后续结构化导出应重建内容，不复用原包。
2. DOCX 页眉页脚、文本框、修订等提取不完整；PDF 分栏、断字、扫描页和图表可能遗漏或错序。界面提供提取限制，仍应与原文核对。
3. 近 30 万字符的高密度识别性能回归已经建立，但解析与花名册匹配仍在主线程；ZIP 只检查声明展开规模，未实现全面恶意文件沙箱。后续应加入可终止 Worker、实际解压预算、超时与 5000 人名单基准。
4. 姓名只匹配花名册；未知姓名、昵称、隐含身份、极少见经历和未覆盖诊断词不会穷尽识别。高置信规则也存在误报。
5. 本地加密保险箱和历史任务尚未实现。模板库已完成收藏、自建、修改和 JSON 包导入导出，但暂不提供批量删除、冲突合并和学校模板签名验证。
6. 本轮实际运行 macOS Chromium 与 Playwright WebKit。Firefox 155 下载版因当前主机无法创建 profile 而未进入应用；Safari、Windows、PWA 实际安装和系统级离线启动尚未验收。已测断网方式为 Chromium 网络离线且生产 Service Worker 已接管。
7. 界面状态协调仍集中在 App；下一步业务模块增多时应按页面拆分并引入明确工作流状态机，继续沿用独立的核心复核契约。
8. 默认单个持久空间不支持多个学校间的同号隔离；V1 以同校学号唯一为前提。无学号名单明确拒绝建立稳定映射。
9. 当前 Git 工作树尚未形成提交基线，项目文件均处于未跟踪状态；本轮未代替用户创建提交或改写仓库历史。

## 隐私 / 数据流风险

- 本地 IndexedDB 当前为明文；同机同浏览器的其他使用者、恶意扩展或设备入侵可能读取。UI 不把“本地”描述为加密或安全保证。
- 手工恢复、替换输入和组合信息仍有识别风险。输出前重新扫描并人工确认；用户可以在明确风险后保留信息，工具不替代合法性和最小必要判断。
- 复制或下载是用户明确触发的本机动作。系统剪贴板、下载目录、操作系统同步/备份和教师随后主动粘贴到外部 AI 超出本应用控制；清除本地映射不撤回这些副本。
- 花名册导入/清除会通知同来源其他持久窗口刷新；会话与演示独立。已修复清除期间迟到的解析结果重新写入 UI 的竞态。
- 模板包使用严格字段白名单，不导出表单填写值，并拒绝明显的手机号、身份证号、邮箱和具体学号；未知姓名或隐含个案信息仍无法可靠自动判定，导入方必须确认包内只有模板定义。模板保存在浏览器 localStorage，未加密。
- 未发现所测流程存在资料上传。该结论有明确测试范围，不是对浏览器扩展、未来代码或未覆盖文件的永久保证。
