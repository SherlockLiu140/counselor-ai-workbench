# AGENTS.md

## 项目名称
班主任 AI 工作台（Counselor AI Workbench）

## 目标用户
高职/大专班主任、辅导员、学工教师。

## 核心产品判断
这是一个「班主任工作流工具」，不是另一个聊天机器人。

不要把首页做成一个大聊天框。
不要让用户先学习 Prompt Engineering。
不要默认把学生原始数据发送给云端模型。

## 最重要的架构原则

### 1. Local First
- 原始学生数据、花名册、脱敏映射表、历史任务默认保留在浏览器本地。
- V1 禁止后端数据库。
- V1 禁止用户登录、账号系统、云同步、遥测、埋点。
- V1 禁止默认调用任何第三方 AI API。
- 能通过本地 JS 完成的处理必须本地完成。
- 网络不可用时，除“打开外部 AI”外，主要功能仍应可使用。

### 2. Privacy by Design
每一个可能包含学生信息的入口，都必须经过：
1. 本地识别；
2. 映射；
3. 泛化；
4. 最小必要；
5. 人工确认；
6. 才允许复制给外部 AI。

界面不得出现“已完全匿名”“绝对安全”等承诺。
统一使用“去标识化/脱敏”“降低识别风险”“请人工复核”等谨慎表述。

### 3. Human in the Loop
自动脱敏不能静默完成后直接发送。
必须提供：
- 原文；
- 脱敏后文本；
- 被识别字段；
- 替换原因；
- 可手工取消/新增脱敏；
- 最终确认按钮。

### 4. No DIY Speech Recognition
不开发 ASR。
工作台只提供：
- “建议使用语音输入”的提示；
- 口述模板；
- 大文本输入框。
推荐文案可提及：Typeless / 豆包语音输入法 / 微信输入法。
不得在代码中集成这些产品 SDK。

### 5. Model Agnostic
V1 默认输出标准 Prompt。
支持按钮：
- 复制 Prompt；
- 复制脱敏文本；
- 打开常用 AI 官网（可配置链接，但不自动携带敏感数据）。
不得自动把内容通过 URL 参数发送给第三方。

V2 才考虑“自带 API Key / 自定义 OpenAI-compatible endpoint / 本地 Ollama”。

## 技术建议

优先：
- Vite + TypeScript
- React 或轻量 Vue（二选一，不要同时使用）
- IndexedDB（Dexie 可选）
- Web Crypto API
- PDF.js（本地打包）
- Mammoth.js（DOCX 文本提取，本地打包）
- SheetJS（XLSX/CSV，本地打包）
- PWA（离线缓存）
- 所有依赖编译进构建产物，不从 CDN 加载

如需单文件展示版，可以额外输出 dist-offline，但主开发版保持模块化。

## 文件格式 V1
必须支持：
- TXT
- CSV
- XLSX
- DOCX
- 可提取文本的 PDF

暂不承诺：
- 扫描版 PDF OCR
- 老式 .doc
- 图片 OCR

遇到不支持的文件应明确提示，不得假装已完成解析。

## 脱敏识别规则 V1

### 直接标识符
- 姓名：优先通过用户本地导入的花名册精确匹配
- 学号：花名册匹配 + 长数字规则
- 手机号
- 身份证号
- 邮箱
- QQ/微信号（仅高置信规则）
- 班级完整名称（可选）
- 宿舍号/详细地址（可选规则）
- 紧急联系人姓名/电话（若花名册中提供）

### 特殊处理
- 同一个学生在同一项目中必须稳定映射为同一个代号，例如 S007。
- 不用 A/B/C 作为长期映射，避免超过 26 人后混乱。
- 映射表仅本地保存。
- 默认不把映射表导出到脱敏文件。
- 用户可“一键清除本地映射”。

### 泛化
提供可选开关：
- 精确出生日期 → 年龄段/年级
- 精确住址 → 市/省级
- 精确时间 → 月份/学期
- 具体医疗诊断 → “心理健康/医疗相关情况”（仅在任务不需要诊断细节时）
- 具体家庭事件 → “家庭近期发生重大变故”
泛化结果必须允许人工修改。

## UI 风格
- 专业、克制、教育系统可接受。
- 不用蓝紫渐变。
- 不做夸张科技感。
- 可使用清晰卡片、白底、少量强调色。
- 优先桌面端，兼容 13–16 英寸笔记本。
- 首页像“工作台”，不是“门户网站”。

## 输出要求
每完成一个阶段：
- 自测；
- 写明已完成项；
- 写明未完成/风险；
- 不擅自扩大需求。
